FRONT-END LAB ASSESSMENT PORTFOLIO

CONTENTS
- index.html: portfolio dashboard
- style.css: responsive visual design
- app.js: search, category filtering, sorting and preview modal
- assessments.json: assessment index generated from your uploaded ZIP
- 24MIC0085/: original HTML files, Bootstrap CSS, images and supporting assets

HOW TO RUN
Recommended (VS Code):
1. Extract this ZIP file.
2. Open the fe_lab_portfolio folder in Visual Studio Code.
3. Install/enable the Live Server extension if needed.
4. Right-click index.html and choose "Open with Live Server".
5. Search/filter the assessment cards and click one to preview the original page.

Alternative using Python:
1. Open a terminal inside this folder.
2. Run: python -m http.server 8000
3. Open: http://localhost:8000

NOTES
- The original assessment files and their relative asset folders are preserved.
- The portal indexes all top-level HTML files found in the ZIP. Some files such as customer.html, payment.html and cart.html are individual parts of the checkout exercise; they are included separately so none of your work is omitted.
- The count is the number of HTML files indexed, not a claim that every file is a separately numbered faculty assessment.
- EX1_9.PDF in the source ZIP appears to be a file with a PDF extension; it has been preserved unchanged.
